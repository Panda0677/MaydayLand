# Figma 导入方式

这个文件夹是一个本地 Figma Dev Plugin，用来把 11 个低保真页面生成到你当前打开的 Figma 文件里。

## 使用步骤

1. 打开 Figma 桌面端，并进入你要写入的设计文件。
2. 菜单选择 `Plugins` → `Development` → `Import plugin from manifest...`。
3. 选择这个文件：`/Users/xiongmaonao67/Desktop/演唱会版闲鱼/figma-import/manifest.json`。
4. 再次打开 `Plugins` → `Development` → `演唱会低保真页面导入器`。
5. 运行后会新增一页：`演唱会闲置交易平台 / 低保真原型`。

生成内容包括：

- 11 个手机页面低保真原型
- 一组可复制/拖动的基础组件
- 所有文本均为 Figma Text，可直接双击修改
- 所有卡片、列表、按钮、筛选项等均为独立 Frame，可直接拖动调整
